# 수동 QA 체크리스트 (공부 기록 · 인안나)

브라우저에서 `index.html`을 연 뒤 순서대로 확인합니다.

## 기록·목표

- [ ] 하루 목표·주간 목표·퀘스트 저장 후 새로고침해도 값이 유지된다.
- [ ] 기록 대시보드에 이번 주 누적·주간 목표 진행 문구가 맞는다.
- [ ] 오늘 목표 분을 채우면 상단 배너(목표 달성)가 뜨고 닫기로 사라진다.

## 타이머·태그·포모

- [ ] 기본 태그 입력 후 타이머 기록 저장 시 최근 기록에 태그가 붙는다.
- [ ] 포모 집중 종료 시 세션 메모가 기록에 남고 입력칸이 비워진다.
- [ ] 포모 실행 중 1초마다 시계·독만 부드럽게 바뀐다(전체 UI 끊김 없음).
- [ ] 타이머 실행 중 1초마다 타이머 표시·독만 갱신된다.
- [ ] 진행 상태 영역에 태그별 누적 요약이 보인다.
- [ ] 포모 주간/월간 세션 수 문구가 증가한다.

## 스토리·접근성

- [ ] 캐릭터 탭에서「인안나에게 한 줄」저장 시 스토리 로그에「나의 한 줄」로 남는다.
- [ ] 보기 하위 버튼이 중첩 탭이 아니라 그룹+region으로 읽힌다(스크린리더로 한 번 확인 권장).

## 연속일·알림 배너

- [ ] 연속일이 있는 날, 17시 이후·오늘 0분이면 연속일 경고 배너가 뜬다(조건 맞을 때만).

## 통계 탭

- [ ] 상단「통계」탭(또는 기록 사이드의「통계」)에서 진행 상태·그래프·주간 리포트·히트맵·최근 기록이 보인다.
- [ ] Alt+2로 통계 탭으로 전환된다.

## 최근 기록 필터·삭제·되돌리기

- [ ] 통계 탭에서 시작일·종료일·태그 포함·이번 주만·정렬을 바꾸면 목록이 즉시 필터된다.
- [ ] 행의「삭제」후 하단 스낵바에서「되돌리기」하면 기록이 복구된다(약 8초 이내).
- [ ] 수정 모드 안의「삭제」도 동일하게 되돌리기가 동작한다.

## 타이머·포모(백그라운드 탭)

- [ ] 다른 탭으로 전환한 뒤에도 타이머·포모 시간이 크게 어긋나지 않는다(가시성 복귀 시 보정).
- [ ] 백그라운드일 때 브라우저 탭 제목에 남은 시간(타이머/포모)이 붙었다가, 다시 이 탭을 보면 원래 제목으로 돌아온다.

## 주간 리포트·지난주 한 줄

- [ ] 주간 리포트 카드에「지난주(… ) 총 …분 · 포모 …회」한 줄 요약이 보인다.

## PWA·오프라인

- [ ] `http(s)`로 열었을 때(로컬 서버 등) 개발자 도구 Application → Service workers에 `sw.js`가 등록된다.
- [ ] 한 번 로드한 뒤 네트워크를 끊고 새로고침해도 앱 본문이 열리는지 확인한다(폰트는 캐시되지 않았을 수 있음).

## 접근성(탭 포커스)

- [ ] 상단「기록」「통계」「보기」를 누른 뒤 해당 패널 안의 첫 버튼 등으로 포커스가 이동한다.
- [ ] 보기 탭에서「캐릭터」「스토리 다시보기」를 바꾼 뒤 활성 서브 탭 버튼에 포커스가 간다.

## 자동 테스트

- [ ] 릴리스 전 `node tests/state-snapshot.mjs`와 `node tests/regression.mjs`를 실행해 모두 통과하는지 확인한다.
